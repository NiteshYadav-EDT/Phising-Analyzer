API Reference

POST /api/scan

Analyzes a URL for phishing threats and returns a comprehensive security report.

Request Body:

{
  "url": "https://example.com"
}

Response:

{
  "riskScore": 75,
  "riskLevel": "Dangerous",
  "checks": [
    {
      "name": "HTTPS Encryption",
      "status": "pass",
      "message": "Valid SSL certificate detected"
    }
  ],
  "domainInfo": {
    "domain": "example.com",
    "registrar": "GoDaddy",
    "country": "United States"
  }
}

Rate Limits:

  • • 5 requests per minute per IP address
  • • 429 HTTP status for exceeded limits
  • • Automatic cleanup of expired data

Integration Examples

JavaScript Integration

const response = await fetch('/api/scan', {
  method: 'POST',
  headers: { 'Content-Type': 'application/json' },
  body: JSON.stringify({ url: 'https://example.com' })
});

const result = await response.json();
console.log(`Risk Score: ${result.riskScore}`);

Python Integration

import requests

def analyze_url(url):
    response = requests.post(
        'https://phishing-analyzer.cyberedt.com/api/scan',
        json={'url': url}
    )
    return response.json()

result = analyze_url('https://example.com')
print(f"Risk Level: {result['riskLevel']}")

cURL Example

curl -X POST https://phishing-analyzer.cyberedt.com/api/scan \
  -H "Content-Type: application/json" \
  -d '{"url": "https://example.com"}'

Troubleshooting

Rate Limit Exceeded

Wait for the rate limit to reset (up to 1 minute) or implement request queuing.

Invalid URL Format

Ensure URLs include protocol (http:// or https://) and are properly formatted.

CORS Errors

Check that your API requests include proper headers and originate from allowed origins.

Slow Response Times

Implement client-side caching for repeated requests and handle timeouts appropriately.
